示例题 · 矩形面积

示例提交 A（WA） → 示例提交 B（AC） · C++

示例题意：输入两个不超过 10⁹ 的正整数 w、h，输出面积。两个变量在代码中声明为 int。正式分析只使用你选中的题面和代码。
− 18　long long area = w * h;
+ 18　long long area = 1LL * w * h;
代码可直接核对

乘法表达式新增了 1LL，使中间运算采用 long long。

先解释，再下结论。

可能原因 · 待验证中间乘积可能超出 int 范围

把结果赋值给 long long，并不会改变右侧两个 int 相乘时的计算类型。对于较大输入，原表达式可能发生有符号整数溢出。

候选测试 · 尚未运行w = 50000，h = 50000

数学结果为 2500000000，超过 32 位有符号整数上限。需要实际执行以记录程序行为；不能预言有符号溢出一定输出某个值。

后一次 AC 是判题事实，但不能单凭 WA → AC 认定所有错误原因均已证明。
