# VP Lab 训练房

在同一台电脑上独自或和最多两名队友参加一场 Codeforces 历史赛，查看房间榜，并在赛后记录自己还要补的题。Windows 安装 Python 3.10 或更高版本后，双击 [启动VP.cmd](启动VP.cmd)，或在项目根目录运行：

```powershell
python vp_demo/server.py --duo --browser --port 8766
```

1. 打开 `http://127.0.0.1:8766/duo` 并登录。创建回放房无需 CF 账号；实战房需要每人填写自己的 CF handle。队友在本机另一个独立浏览器会话里打开邀请链接，登录后点击加入。
2. 房主选场并确认。当时长是唯一限制时，按钮会显示需要延长到多少分钟。每位队友独立确认后，房主才能开赛；单人无需等待。新成员加入会清除旧的选场和确认。
3. 开赛后看题和房间榜。**实战**在 CF 原站提交，每人同步自己的公开提交。**回放**可推进合成事件，不会写入真实提交。终场后打开自己的未通过题，按实际情况记录补题完成。自报完成不等于 CF 通过。

安装离线赛库时，程序自动读取 `vp_demo/data/vp-ready.zip`，可按比赛名称或编号搜索，开赛后可以离线读题。未安装时可用内置的小目录（第 1、4 场）及原题链接。也可用 `VPLAB_CONTESTS` 指定另一份兼容的目录。

应用仅监听本机。房间只按已导入的成员历史排除见过的比赛；没有匹配记录不能证明从未做过。本项目的房间榜使用通过题数及罚时，不代表 CF 正式成绩。
